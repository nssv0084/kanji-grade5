## 2. 書き取りの画面（K-02、スマホ）

```text
┌────────────────────────┐
│ 明日は［しょう］［たい］  │  ← 問題文。答えの部分は読みを表示し、
│ された会に行く。          │     いま書いている字を強調する
│                        │
│   1字目 / 2字           │
│ ┌────────────────────┐ │
│ │         ┊          │ │
│ │         ┊          │ │  ← 画面幅いっぱいのマス（1字ずつ）
│ │┈┈┈┈┈┈┈┈┼┈┈┈┈┈┈┈┈┈┈│ │     十字の補助線
│ │         ┊          │ │
│ │         ┊          │ │
│ └────────────────────┘ │
│ [1画もどす] [書き直す]    │
│ [  つぎの字へ / こたえる ] │  ← 最後の字で「こたえる」になる
└────────────────────────┘
```

- マスは画面幅から左右の余白（16px ずつ）を引いた正方形。大きくても 420px まで。
- マスの上で指を動かしても、ページがスクロール・拡大しない。2本目の指は無視する。
- 1字書いたら「つぎの字へ」で次のマスに進む。問題文の［ ］を押すと、その字に戻って書き直せる。
- 答えたあとは、自分の字と手本を並べ、違う画を色で示す（照合で分かる範囲）。

### 試作（ステップ1）の画面

学習の画面を作る前に、判定だけを試す画面を作る。AWS を使わず `npm run dev` で動かし、同じ Wi-Fi のスマホから開く。

- 5年生の193字から1字を選ぶ（ランダム、または字を指定）。読みを表示し、手本は「手本を見る」で表示する。
- 書いて「判定する」を押すと、正解・あいまい・不正解と、画数・書き順・画ごとのずれ・形が近い字（上位3字）を表示する。
- 「実際は正しく書けていた？」に答えると、筆跡と判定の結果を端末内に記録する。記録の件数と誤判定率を表示し、「PC に送る」で開発サーバーの PC の samples/ に送るか、JSON で書き出せる（筆跡はリポジトリに入れない。samples/ は .gitignore 済み）。
- しきい値は画面の下で変えられる。

## 3. 月例テスト

### 3.1 テストの PDF（A4、TST-05）

```text
┌──────────────────────────────────────┐
│■                                    ■│ ← 四隅の目印（写真の位置合わせ用）
│ 11月の漢字テスト        名前 ________   [QR]│ ← QR はテストの ID
│                                        │
│ 1  明日は ［  ］［  ］ された会に行く。      │ ← 書き取り: 1字1マス
│          しょう たい                      │
│ 2  ……                                   │
│ ……                                      │
│ 21 招待状がとどいた。 （          ）       │ ← 読み: ふりがなの枠
│ ……                                      │
│■                                    ■│
└──────────────────────────────────────┘
```

- 字は Klee One（教科書体に近いフォント）で印刷する。マスは 15mm 角を目安にし、十字の補助線を薄く入れる。
- 1枚に収まらないとき（50問の回）は2枚にし、各ページに目印と ID（ページ番号つき）を入れる。
- 横書きで作る（要件定義書 11章の7）。

### 3.2 採点の確認（P-11）

- 写真を取り込むと、問題ごとに「解答欄の切り抜き・読み取った字・正答・判定（○・×・読み取れない）」を1行ずつ並べる。
- 「読み取れない」と自信の低い行を上にまとめ、確認しないと確定できない（TST-09）。各行の判定は押して切り替えられる。
- とめ・はね・はらいの指摘は、その行に参考として小さく表示する（点数には入れない）。
- 写真が使えないときは、理由（暗い、斜め、解答欄が切れている、ID が読めない）と撮り直しのボタンを出す（TST-10）。
