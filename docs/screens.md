# 小学5年 漢字トレーニング 画面一覧

- 版: 0.1（ドラフト）
- 作成日: 2026-10-18
- 関連: [要件定義書](requirements.md)

## 1. 画面一覧

### 共通

| ID | 画面名 | 概要 |
|---|---|---|
| C-01 | ログイン | ログインIDとパスワードを入力する |
| C-02 | 初回パスワード変更 | 仮パスワードでのログイン後に、自分のパスワードを設定する |

### 子ども

| ID | 画面名 | 概要 |
|---|---|---|
| K-01 | ホーム | 今日の練習（残りのセット数）、連続学習日数、覚えた字数／193字、お祝い表示 |
| K-02 | 問題 | 1問ずつ解く。書き取りは手書きのマス、読みはひらがな入力、送りがな・熟語は4択 |
| K-03 | 解答結果（K-02 内） | 正誤、正答、自分の字と手本の比較、書き順のアニメーション、「合っているよ」「問題がおかしい」のボタン |
| K-04 | セット結果 | セットの正答数、間違えた問題、次のセットへのボタン |
| K-05 | 漢字マップ | 193字のマス目を定着度で色分け。マスを押すと漢字の詳細（読み、熟語、成績、この字だけ練習） |
| K-06 | 自由練習 | 形式と問題数を選んで始める |
| K-07 | まとめテスト | 書き取り・読みのテスト。最後にまとめて結果を出す |
| K-08 | 設定 | パスワード変更、ログアウト、ホーム画面への追加方法、クレジット |

### 保護者

| ID | 画面名 | 概要 |
|---|---|---|
| P-01 | ダッシュボード | 子どもの状況、苦手な漢字、確認待ちの件数、API 使用額 |
| P-02 | 写真の取り込み | ドリルのページを撮影・選択してアップロードする。読み取りの進み具合 |
| P-03 | 読み取り結果の確認 | 写真と並べて、読み取った漢字・読み・熟語を確認・修正し、確定する |
| P-04 | 習った漢字 | 193字の一覧。習った日の登録・取り消し（写真を使わない登録） |
| P-05 | 問題一覧・編集 | 漢字・形式・状態で絞り込み、編集、無効化、手入力での追加 |
| P-06 | 確認待ち | 生成した問題、「合っているよ」の申し立て（手書きの画像つき）、問題の報告 |
| P-07 | 子どもの詳細 | 漢字ごとの成績、日別の学習量、まとめテストの結果、判定ミスの多い漢字 |
| P-08 | アカウント | 子ども・保護者の追加、仮パスワードの再発行 |
| P-09 | 設定 | 予算、使用モデル（用途別）、1日の問題数、AI 判定の上限、未学習アラートの日数、まとめテストの問題数 |

## 2. 書き取りの画面（K-02）

```text
┌──────────────────────────────────┐
│  明日は ［  ］［  ］ された会に行く。     │  ← 答えの部分は読みをふりがなで表示
│        しょう たい                     │
│                                      │
│   ┌────────┐ ┌────────┐            │
│   │   ┼    │ │   ┼    │            │  ← 1マス1字。十字の補助線
│   │        │ │        │            │
│   └────────┘ └────────┘            │
│                                      │
│  [1画もどす] [書き直す]     [こたえる]   │
└──────────────────────────────────┘
```

- マスはタブレットの横向きで1辺 200px 以上を目安にする。
- 書いている間はページがスクロールしない。
- 答えたあとは、マスの下に手本を並べ、違う画を色で示す（照合で分かる範囲）。
